In v4.0, the Year view is an opt-in plugin exported from `@ilamy/calendar/plugins/year`, keeping the default core bundle lighter when you only need Month, Week, and Day views.

## Usage

```tsx
import { IlamyCalendar } from '@ilamy/calendar/react'
import { yearPlugin } from '@ilamy/calendar/plugins/year'

const plugins = [yearPlugin()]

export function App() {
  return (
    <IlamyCalendar
      events={events}
      initialView="year"
      plugins={plugins}
    />
  )
}
```

Memoize or hoist the `plugins` array outside the component so its identity remains stable across renders.
