# Development Log - 2026-09-30

## Changes

- **[sticky titles]** (#290, reported on PR #292): A long event's title now also stays in view when the PAGE scrolls, not only the calendar's own scroller.
  - The report: a 1000px week in the demo, with the page scrolled. The regular grid's header sits outside the calendar's scroller, so `stickyViewHeader` pins it to the window, and the tall events slid under it with their titles.
  - A sticky element only responds to its nearest scroll container (MDN, `position: sticky`), which for the title is the grid's own. So CSS alone could not follow the page.
  - Measured before the fix: page scrolled 300px, grid scroll 0, header covering 0 to 73px, title at 1px.
- **[useStickyInsets]**: The insets are now how far into the viewport the reader cannot see, measured as positions against the viewport's edges rather than as sizes. The furthest of these wins:
  - The grid's own marked sticky column and header, now looked up in the whole grid (`rootRef`), so a regular grid's header outside the scroller counts.
  - That header once it is pinned to the window.
  - The window's own top-left, and every clipping ancestor (overflow `hidden`, `scroll`, `auto`, `overlay` or `clip`; found once per subscription).

  It re-measures on `scroll` of the window and each such ancestor, and on window `resize`. Listeners are passive, coalesced to one measurement per animation frame; a frame requested from a scroll event runs before that frame paints.
- **[beyond FullCalendar]**: FullCalendar pins headers to the window only with `height: 'auto'` (`stickyHeaderDates: 'auto'`, https://fullcalendar.io/docs/stickyHeaderDates), where it has no inner scroller and `fc-sticky` follows the page for free. With a fixed height its titles follow only its own scroller. We follow the page in both cases; the maintainer chose this (option 1 of 3) over matching FullCalendar by un-pinning the header. The website docs state the difference.

- Revert-proofed:

  - Measuring markers only inside the viewport fails the stuck-header case (e2e and unit).
  - Dropping the window edge fails the no-sticky-header case (e2e and unit).
- In a regular week the header's sticky block includes the all-day row, so the title clears the all-day row's bottom, not the day header's.
