## Notes

Verified during the #241 review and worth keeping: `startOf('day')` on a `.tz()` instance measures ~34.6µs here versus a fraction of a microsecond on a plain instance, so any per-day boundary computed inside an event loop is a genuine hot spot once a `timezone` prop is set. Also measured that a `WeakMap` bounds cache keyed on event object identity is ~1.8x faster than recomputing `.valueOf()` inline on a primed 512-event scan, which refuted a reviewer agent's claim that it was dead weight.

Release-gate gotcha found today: `bun run ci | tail -n` reports `tail`'s exit code, not the gate's, so a failing gate reads as success. Capture the exit code without a pipe (`bun run ci > log 2>&1; echo $?`).
