### Changes

- **[v4/phase3-renderer]**: Replaced the imperative DOM builder (`lib/dom/`) with a unified `preact@11.2.0` renderer under `packages/calendar/src/lib/renderer/` (`mount-calendar.tsx`, `calendar-app.tsx`, `slot-host.tsx`, `mini-calendar.tsx`, `dialog-shell.tsx`, `calendar-header.tsx`, `view-menu.tsx`, `event-form-dialog.tsx`, `more-events-dialog.tsx`, `recurrence-scope-dialog.tsx`, `month-view.tsx`, `month-grid-cells.tsx`, `time-grid-view.tsx`, `resource-horizontal-grid.tsx`, `event-bar.tsx`, `agenda-view.tsx`, `year-view.tsx`, plus formatters, recurrence compat, async fetcher, and scroll-to-time utilities).

- **[v4/phase3-css-and-a11y]**: Fixed six defect classes across the renderer and CSS layers (`packages/calendar/styles/base.css`, `packages/calendar/styles/theme.css`):
  - **ARIA `aria-required-children`**: Added optional `role?: 'gridcell'` on `MonthEventsOverlay` (`month-grid-cells.tsx`) passed only by `month-view.tsx` (omitted in `resource-horizontal-grid.tsx`) so all buttons/event-bars inside month `role="row"` sit inside a `role="gridcell"`.
  - **Nested Escape ordering & commit-phase listener attachment**: Added `attachWindowEscapeTracker` + `onCancel` guard in `DialogShell` (`dialog-shell.tsx`) and switched `PopoverShell` (`mini-calendar.tsx`) and `ViewMenu` (`view-menu.tsx`) from Preact's RAF-deferred `useEffect` to `useLayoutEffect` so `keydown`/`pointerdown` listeners and coordinates attach synchronously on mount.
  - **Double edges & sticky occlusion**: Added `data-last-col="true"` / `data-last-row="true"` plus dual `:not(:last-child):not([data-last-col='true'])` and `:not(:last-child):not([data-last-row='true'])` rules (covering both overlay-tailed grids and standalone slot consumers, plus `res-h-day-group` which also carries `data-ilamy-slot='day-header'`). Split `header-corner` (`z-index: 35`) from `resource-header` (`z-index: 20`).
  - **Cross-adapter CSS scoping**: Scoped grid `all-day-row` and padded `event-bar` rules (`box-shadow: 0 0 0 1px var(--ilamy-surface)`) onto `data-ilamy-part="all-day-row"` / `data-ilamy-part="event-bar"` so React's legacy `data-ilamy-slot="all-day-row"` flex wrapper and `data-ilamy-slot="event-bar"` outer `AnimatedSection` sticky-title / handle geometry remain intact.
  - **Unstyled mode, i18n, and live slot callbacks**: Moved remaining inline visual styles into `:where([data-ilamy-root]:not([data-unstyled='true']) ...)`, routed hardcoded strings through `actions.t(...)`, and read live `controller.getState()` inside `headerSlotContext.openEventForm` and `stateRef.current` inside `RecurrenceScopeDialog`'s `onConfirm` so initial-mount slot closures stay fresh after navigation.
- **[v4/phase3-e2e]**: Added zero-Tailwind standalone runtime page (`apps/e2e/zero-tailwind.html`, `zero-tailwind-entry.ts`), extended `apps/e2e/tests/zero-tailwind-styles.spec.ts`, added `apps/e2e/tests/phase3-renderer-parity.spec.ts` (Rule 5 calibration + Check Groups A-F across frameworks), and added Vite `optimizeDeps` pre-bundling for `vue`, `solid-js`, and `preact` in `apps/demo/vite.config.ts` and `apps/e2e/vite.config.ts`.
