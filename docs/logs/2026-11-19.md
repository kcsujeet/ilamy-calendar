# Development Log - 2026-11-19

## Changes

- **Temporal date core & multi-zone isolation (`4.0.1`–`4.0.3`, `#314`)**: Replaced `dayjs` across the entire monorepo with `temporal-polyfill@1.0.8` (`fns/*` named imports) + `Intl.DateTimeFormat` with explicit `timeZone` in `@ilamy/utils/temporal`. Removed `dayjs`, `Dayjs`, and `ManipulateType` exports and dependencies. All public date outputs are now ISO 8601 strings with explicit offset (`'YYYY-MM-DDTHH:mm:ss±HH:MM'`); public inputs accept `string | Date`. Added optional `timezone?: string` on `CalendarEvent`. Fixed `now()` to read `Date.now()` before converting through `Temporal.Instant` so fake test clocks (Playwright `page.clock.install`, Vitest, Jest, Bun) control the calendar clock even in runtimes with native `Temporal`.
- **Headless core & styling adapters (`D5`)**: Extracted framework-agnostic `@ilamy/core` (zero React, zero CSS, exported publicly at `@ilamy/calendar/core`). Added `unstyled`, `slotProps`, and swappable `components` to `IlamyCalendar`. Shipped first-party `@ilamy/calendar/themes/mui` (`@mui/material` optional peer) and `@ilamy/calendar/themes/stylex` (`@stylexjs/stylex` optional peer).
- **Plugins extraction (`D7`)**: Extracted Year view into `packages/plugins/year` (`@ilamy/calendar/plugins/year`) and iCal export into `packages/plugins/ical` (`@ilamy/calendar/plugins/ical`) with `SLOT_TOOLBAR` and RFC 5545 §3.6.5 `DTSTART;TZID=` + `VTIMEZONE` support. Removed `hideExportButton`.
- **Standards alignment (`D3`, `D8`–`D11`, `4.0.5`, `4.0.6`, `4.0.9`)**:
  - `editable` defaults to `false`; `nowIndicator` defaults to `false`.
  - `displayEventTime` defaults to `true`; `displayEventEnd` defaults to `false` in month view and `true` in time-grid views.
  - `onDateChange` / `currentRange` trims to drawn days when `hiddenDays`/`weekends` hide days.
  - Month cell clicks and drag-to-create selections report `allDay: true`; fixed `useScrollToTime` (`scrollToNow`) to fall back to `[data-start]` day cells in day-only grids (resource month) where all cells carry `data-all-day="true"`.
  - `businessHours` and month padding days shade visually (`data-non-business="true"`, `data-disabled="false"`) without blocking drops/clicks; added `eventConstraint="businessHours"` and `selectConstraint="businessHours"`.
  - Removed `IlamyResourceCalendar`, `IlamyResourceCalendarProps`, `disableDragAndDrop`, `hideExportButton`.
  - Added visible hover-revealed 3-dot CSS resize handles (`ResizeHandle`, 6px strip matching v3 geometry so narrow bars remain easy to grab for moves).
- **Title picker clock preservation fix**: Fixed `MonthGrid` and `YearGrid` to preserve `hour`, `minute`, `second`, and `millisecond` on `onSelect` when jumping across DST transitions.
- **Consumers, E2E, and docs**: Migrated `packages/playground`, `apps/demo`, `apps/website`, `examples/{astro,nextjs,vite}`, and `apps/e2e` (harness, 1,300+ existing specs, new `v4-features.spec.ts`, and expanded `demo-defaults.spec.ts` real-pointer tests). Verified timezone specs under `UTC`, `America/Vancouver`, `Europe/London`, and `America/Havana`.

- **Fallow static analysis & DRY cleanup**: Extracted shared RFC 5545 date/TZID formatting helpers into `@ilamy/utils/ical-format` (`packages/utils/src/ical-format.ts` + unit tests) consumed by both `packages/plugins/ical` and `packages/plugins/recurrence`, deduplicated binary search in `packages/core/src/core-layout-columns.ts` and resource layout dispatch in `views/resource-axis.tsx`, removed unused internal exports and redundant type re-exports, removed unused `@stylexjs/stylex` devDependency from `@ilamy/theme-stylex`, updated `fallow.toml` for bundled runtime deps (`@radix-ui/react-popover`, `temporal-polyfill`) and MUI test peer deps (`@emotion/react`, `@emotion/styled`), and simplified all complexity-flagged functions (`isRangeWithinBusinessHours`, `calculateResizeTimes`, `convertEventToVEvent`, `formatEventTime`, `generateRecurringEvents`, `CellFrame`, `useRangeFetcher`, `EventForm`, `NoMemoVerticalGridCol`, `TimePicker`, `useCalendarNavigation`). `fallow@3.20.0 audit --changed-since main --gate new-only --no-cache` passes with 0 dead code, 0 complexity, 0 duplication across 412 changed files.
- **Website & docs**: Updated remaining MDX docs (`usage`, `calendar`, `resource-calendar`, `use-ilamy-calendar-context`, `ical-export`, `internationalization`, `recurrence`, `faq`), repo docs (`export-ical.md`, `timezones.md`), and `examples/*/README.md` to v4.0 Temporal/plugin/constraint semantics. Verified `apps/website` `astro build` (30 pages built, 0 errors).
