## Installation

Get started with ilamy Calendar by installing it via your preferred package manager:

<Tabs>
  <TabItem label="npm">
    ```bash
    npm install @ilamy/calendar
    ```
  </TabItem>
  <TabItem label="pnpm">
    ```bash
    pnpm add @ilamy/calendar
    ```
  </TabItem>
  <TabItem label="yarn">
    ```bash
    yarn add @ilamy/calendar
    ```
  </TabItem>
  <TabItem label="bun">
    ```bash
    bun add @ilamy/calendar
    ```
  </TabItem>
</Tabs>

No external date library (`dayjs`, `moment`, `date-fns`), drag-and-drop package (`@dnd-kit/*`), or UI component library (`@radix-ui/*`, `@mui/material`, `lucide-react`, `class-variance-authority`, `clsx`, `tailwind-merge`, `tailwindcss`) is required — `temporal-polyfill` is the only runtime dependency, and v4.0 runs on TC39 Temporal and `Intl.DateTimeFormat` with plain ISO 8601 strings and `Date` inputs.

## Stylesheet (`@ilamy/calendar/styles.css`)

Import the layered stylesheet once in your app entry (works standalone with **zero Tailwind installed**, and no `@source` directive is needed):

```ts
import '@ilamy/calendar/styles.css';
```

If your app uses Tailwind CSS v4, import `@ilamy/calendar/styles.css` **before** `@import 'tailwindcss';` so Tailwind utilities sit in a higher cascade layer and shadcn variables (`--background`, `--foreground`, `--border`, `--primary`, `--muted`, `--radius`, `.dark`) are inherited automatically:

```css title="globals.css"
@import '@ilamy/calendar/styles.css';
@import 'tailwindcss';
```

For completely custom or unstyled builds, import only the structural layout layer (`@ilamy/calendar/styles/base.css`). `@ilamy/calendar/styles.css`, `@ilamy/calendar/styles/stylex`, and `@ilamy/calendar/styles/mui` are pure token and CSS integrations with zero framework lock-in. See [Styling & Themes](/docs/customization/styling).

## Peer dependencies

`temporal-polyfill` is the **only** required runtime dependency. Zero UI component libraries (`@radix-ui/*`), drag-and-drop libraries (`@dnd-kit/*`), MUI components, icon packs (`lucide-react`), or Tailwind packages are bundled.

All framework, feature, and styling peer dependencies are **optional** — install only what you use:

### Frameworks
- `react` and `react-dom` (`^19.2.0`) — for `@ilamy/calendar/react` (React 19)
- `vue` (`^3.5.0`) — for `@ilamy/calendar/vue` (Vue 3.5+, zero React dependency)
- `svelte` (`^5.0.0`) — for `@ilamy/calendar/svelte` (Svelte 5+, zero React dependency)
- `solid-js` (`^2.0.0`) — for `@ilamy/calendar/solid` (Solid 2.0+, zero React dependency)
- `@angular/core` (`^22.0.0`) — for `@ilamy/calendar/angular` (Angular 22+, zero React dependency)

### Optional Features
- `rrule` — optional peer dependency needed only when using `@ilamy/calendar/plugins/recurrence`.

### Styling (Pure CSS & Tokens — framework-agnostic)
- `tailwindcss` — genuinely optional; `@ilamy/calendar/styles.css` renders standalone with zero Tailwind
- `@stylexjs/stylex` — optional types for `@ilamy/calendar/styles/stylex`

All framework wrappers and Vanilla DOM share the same built-in zero-dependency pointer drag/resize engine and pure token integrations (`@ilamy/calendar/styles.css`, `@ilamy/calendar/styles/stylex`, and `@ilamy/calendar/styles/mui`) with zero framework lock-in. The headless core (`@ilamy/calendar`) and Vanilla DOM renderer (`@ilamy/calendar/dom`) require zero framework peer dependencies. See [Multi-Framework Support](/docs/frameworks/overview) for guides across all frameworks.

To localize date labels, set the `locale` prop to any BCP 47 locale tag (such as `"fr"`, `"de"`, `"ja"`, `"ar"`). No locale imports are needed. See [Internationalization](/docs/features/internationalization).
