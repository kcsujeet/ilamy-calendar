Verified visually on `http://localhost:4100/` (Vue 3.5 + StyleX screenshot) and via `bun run format`, `bun run lint`, `@ilamy/dom` tests (15/15), Playwright E2E parity suite (4/4), and `fallow audit` (`0 / 0 / 0`).
- **[theming/grid-borders]**: Eliminated double 2px borders on the calendar body in MUI and StyleX by removing redundant per-cell `borderRight`/`borderBottom` from `mui-theme.ts` and `stylex-theme.ts`, routing React's internal `gap-px bg-border` separators through `usesGridBorder` (`!unstyled || Boolean(slotProps?.grid?.style?.border)`), and adding `border-r last:border-r-0 border-b border-border` in `@ilamy/dom`'s `applySlot` when `slotProps.grid.style.border` is active. - **[dom/scroll & scrollbar]**: Removed `overflow: 'hidden'` from `grid.style` in `stylex-theme.ts` and `mui-theme.ts` (React's outer non-scrolling `gridSlot` already handles clipping; `@ilamy/dom` applies the `grid` slot directly to its scroll container, so inline `overflow: hidden` broke scrolling in Vue/Svelte/Solid/Angular + StyleX). Added a defensive guard in `packages/dom/src/core/dom-styles.utils.ts` so `grid` never drops scrollability and uses a clean thin scrollbar (`scrollbarWidth: 'thin'`). Expanded `apps/e2e/demo-tests/theme-and-framework-parity.spec.ts` to drive real mouse-wheel scrolling across Vue, Svelte, Solid, and Angular in both Tailwind and StyleX (4/4 passing, Fallow `0 / 0 / 0`).
