Get up and running with ilamy Calendar in just a few minutes.

## Basic Setup

Once you've installed the package, follow these steps to configure and use the calendar:

<Steps>

1. ### Configure Tailwind CSS

   Since ilamy Calendar is built with Tailwind CSS v4, you need to register the source path in your CSS file to ensure all component styles are included:

   ```css title="globals.css"
   @source "../node_modules/@ilamy/calendar/dist";
   ```

   <Aside>
   This tells Tailwind to scan the calendar package for classes and include them in your build. This is especially important since node_modules are typically ignored by Tailwind by default.
   </Aside>

2. ### Import and Use the Calendar

   Now you can start using the calendar with minimal configuration. Events accept plain ISO 8601 strings or native JavaScript `Date` objects — no `dayjs` setup or plugin registration is needed:

   ```tsx title="MyCalendar.tsx"
   import { IlamyCalendar } from '@ilamy/calendar';

   const events = [
     {
       id: '1',
       title: 'Team Standup',
       start: '2026-03-02T09:00:00-05:00',
       end: '2026-03-02T09:30:00-05:00',
     },
   ];

   export default function MyCalendar() {
     return (
       <div className="p-6">
         <IlamyCalendar events={events} editable />
       </div>
     );
   }
   ```

3. ### Add plugins (optional)

   The core ships **no plugins** by default. Capabilities like recurring events, agenda view, year view, iCalendar export, and drag-to-create are opt-in: import them from their subpath and register them via the `plugins` prop. Skip this step if you don't need them.

   ```tsx title="MyCalendar.tsx"
   import { IlamyCalendar } from '@ilamy/calendar';
   import { recurrencePlugin } from '@ilamy/calendar/plugins/recurrence';
   import { yearPlugin } from '@ilamy/calendar/plugins/year';
   import { icalPlugin } from '@ilamy/calendar/plugins/ical';

   export default function MyCalendar() {
     return (
       <div className="p-6">
         <IlamyCalendar
           plugins={[recurrencePlugin(), yearPlugin(), icalPlugin()]}
         />
       </div>
     );
   }
   ```

</Steps>
