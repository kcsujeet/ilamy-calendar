`@ilamy/calendar` v4.0 follows a symmetric entry-point design: the root `@ilamy/calendar` export is the pure headless framework-agnostic core, paired with equal sibling wrappers for **React 19**, **Vue 3.5**, **Svelte 5**, **Solid 2.0**, **Angular 22**, and **Vanilla DOM** — all sharing one CSS contract at `@ilamy/calendar/styles.css`.

Every adapter runs on the same TC39 Temporal date core, shared view-model builders, layout engine, RFC 5545 recurrence engine, business-hours & constraint validator, and styling contract (`--ilamy-*` tokens, `unstyled`, `slotProps`, and `@ilamy/calendar/themes/stylex`). **Vue, Svelte, Solid, Angular, and DOM bundles import zero React code and require zero Tailwind.**

## Entry Points

| Target | Import | Version | What it exports |
| --- | --- | --- | --- |
| **Headless Core** | `@ilamy/calendar` | Any JS/TS | `createCalendarController`, Temporal helpers, layout engines, shared view-model builders, `defaultTranslations`, `createTranslator`, shared domain types (`CalendarEvent`, `Resource`, `BusinessHours`, `Translations`, etc.) |
| **React** | `@ilamy/calendar/react` | React 19.2+ | `<IlamyCalendar />`, `useIlamyCalendarContext`, `CalendarThemeProvider`, `useSlotProps`, `useCalendarComponents`, `SLOT_*`, `IlamyPlugin` |
| **Vue** | `@ilamy/calendar/vue` | Vue 3.5+ | `<IlamyCalendar />` component (props, emits, scoped slots `#event`/`#header`/`#resource`/`#event-form`, `expose()`), `useIlamyCalendar` composable |
| **Svelte** | `@ilamy/calendar/svelte` | Svelte 5+ | `ilamyCalendar` Svelte 5 Attachment (`{@attach}`), `ilamyCalendarAction` (`use:`), `createIlamyCalendar` (`svelte/reactivity`) |
| **Solid** | `@ilamy/calendar/solid` | Solid 2.0+ | `<IlamyCalendar />` component, `createIlamyCalendar` (Solid 2 signals & memos) |
| **Angular** | `@ilamy/calendar/angular` | Angular 22+ | `registerIlamyCalendarElement`, `IlamyCalendarElement` (`<ilamy-calendar>` Custom Element with `[options]`/`[events]` & typed `CustomEvent`s), `createAngularCalendar` |
| **Vanilla DOM** | `@ilamy/calendar/dom` | Browser DOM | `mountCalendar`, `generateDomIcal`, `DomCalendarOptions`, `MountedCalendar`, render-context types |
| **Stylesheet** | `@ilamy/calendar/styles.css` | Pure CSS | Combined layered CSS (`@layer ilamy.base, ilamy.theme`) — works standalone without Tailwind and auto-bridges shadcn CSS variables |

## Bring Your Own Design System (Every Framework)

All frameworks share the exact same customization contract:

- **Zero-config layered CSS:** `import '@ilamy/calendar/styles.css'` works with zero Tailwind installed and automatically bridges shadcn CSS variables (`--background`, `--foreground`, `--border`, `--primary`, `--muted`, `--radius`, `.dark`). For Tailwind v4, `@import '@ilamy/calendar/styles.css';` before `@import 'tailwindcss';` requires no `@source` directive.
- **StyleX:** Pass `createStylexCalendarTheme({ mode: 'light' | 'dark' })` from `@ilamy/calendar/themes/stylex` to React, Vue, Svelte, Solid, Angular, or Vanilla DOM.
- **Unstyled + `slotProps` + `[data-ilamy-slot]`:** Import `@ilamy/calendar/styles/base.css` (structural layout only) or pass `unstyled: true` with `slotProps` (`root`, `header`, `toolbar`, `navButton`, `viewButton`, `viewButtonActive`, `grid`, `dayHeader`, `cell`, `cellToday`, `cellDisabled`, `cellNonBusiness`, `allDayRow`, `eventBar`, `resizeHandle`, `nowIndicator`, `moreLink`, `resourceHeader`) or override `[data-ilamy-slot="..."]` directly in CSS.
- **Custom renderers:** Override events, headers, resources, and event forms using native React props, Vue scoped slots (`#event`, `#header`, `#resource`, `#event-form`), or DOM mount hooks (`renderEvent`, `renderHeader`, `renderResource`, `renderEventForm`).
- **Material UI (`@ilamy/calendar/themes/mui`):** Native MUI theme bridge (`useMuiCalendarTheme` / `createMuiCalendarTheme`) and MUI component primitives (`muiCalendarComponents`) for React consumers.
