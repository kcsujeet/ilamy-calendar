# Development Log - 2026-11-21

## Changes

- **CI E2E speedup & Fallow CI fix**:
  - **Sharding + caching (`.github/workflows/ci.yml`)**: Split `e2e` across 4 parallel shards (`--shard=${{ matrix.shard }}/4`, `fail-fast: false`), cached `~/.bun/install/cache` and `~/.cache/ms-playwright`, and switched CI E2E web servers to pre-built static `vite preview` bundles (`@ilamy/e2e` + `@ilamy/demo`, ~0.4s build) instead of unbundled dev mode.
  - **Reduced-motion support (`AnimatedSection` + Playwright)**: Added `motion-reduce:animate-none motion-reduce:duration-0` to `AnimatedSection` and enabled `reducedMotion: 'reduce'` in `apps/e2e/playwright.config.ts` so 500ms enter animations complete immediately during E2E runs.
  - **Removed dead waits & redundant reloads in E2E specs**: Replaced `waitForTimeout(700)` in `slot-snap-personas.spec.ts`'s `openSettled` (called 181+ times) with condition polling, replaced 14 hardcoded `waitForTimeout(2500 + 400 + 400)` auto-scroll sleeps with `waitForScrollEdge` polling, computed DST baseline drops once instead of 3× per test, and replaced animation `waitForTimeout(600..800)` sleeps in `visible-hours-personas`, `formats-qa`, `display-toggles-qa`, `resources`, and `ref-api` with `settleAnimations` / `waitForDragRender`.
  - **Fallow CI resolution (`packages/playground/tsconfig.json`)**: Added source `paths` aliases for `@ilamy/calendar/*` subpaths so CI's Fallow job resolves them cleanly without needing `packages/calendar/dist/` pre-built.
