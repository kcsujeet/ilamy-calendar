ilamy Calendar separates **styling** (`CSS` via stylesheets, `--ilamy-*` variables, and `slotProps`) from **component UIs** (`Components` via region-level [`slots`](/docs/customization/components)). Zero Tailwind, zero `@radix-ui/*`, zero `@dnd-kit/*`, and zero `@mui/material` packages are shipped inside `@ilamy/calendar`.

Every recipe below works identically across **React, Vue, Svelte, Solid, and Angular**.

---

## 1. Plain CSS (`@ilamy/calendar/styles.css`)

Import `@ilamy/calendar/styles.css` once in your application entry — **no Tailwind installation or `@source` directive is required**:

```ts title="main.tsx"
import '@ilamy/calendar/styles.css'
```

If your app uses Tailwind CSS v4 or shadcn/ui, import `@ilamy/calendar/styles.css` **before** `@import 'tailwindcss';` so Tailwind utilities sit in a higher cascade layer:

```css title="globals.css"
@import '@ilamy/calendar/styles.css';
@import 'tailwindcss';
```

### Design Tokens & shadcn/Base UI Auto-Bridging

Inside `@layer ilamy.base`, `[data-ilamy-root]` reads `--ilamy-*` tokens that automatically fall back to standard shadcn/Tailwind CSS variables (`--background`, `--foreground`, `--card`, `--muted`, `--muted-foreground`, `--border`, `--primary`, `--primary-foreground`, `--destructive`, `--radius`, `--font-sans`, and `.dark`), with crisp light/dark fallbacks when no theme variables exist:

| Token | Bridges variable | Purpose |
|---|---|---|
| `--ilamy-bg` | `--background` | Calendar and cell background |
| `--ilamy-fg` | `--foreground` | Primary text color |
| `--ilamy-surface` | `--card` | Surface & bar separation border |
| `--ilamy-muted` | `--muted` | View switcher track, hover & non-business tint |
| `--ilamy-muted-fg` | `--muted-foreground` | Secondary labels & outside-month text |
| `--ilamy-border` | `--border` | Grid borders & control borders |
| `--ilamy-primary` | `--primary` | Today badge, primary actions & default event bars |
| `--ilamy-primary-fg` | `--primary-foreground` | Text on primary surfaces |
| `--ilamy-danger` | `--destructive` | Current-time indicator & delete action |
| `--ilamy-radius` | `--radius` | Border radius for controls, dialogs & event bars |
| `--ilamy-font` | `--font-sans` | Root font family |

### CSS Selector Overrides (`[data-ilamy-slot="..."]`)

All built-in rules in `@layer ilamy.base` and `@layer ilamy.theme` are wrapped in `:where(...)` (zero specificity). Plain CSS rules override them without `!important`:

```css
[data-ilamy-slot='event-bar'] {
  border-radius: 9999px;
  font-weight: 600;
}

[data-ilamy-slot='cell'][data-non-business='true'] {
  background-color: #f9fafb;
}
```

## 2. Structural Only (`unstyled`) & Tailwind Recipe

To strip every visual rule from `@ilamy/calendar/styles/theme.css` while keeping flex/grid layout, sticky headers, scrolling, and accessibility attributes intact, import `@ilamy/calendar/styles/base.css` (or set `unstyled`) and supply Tailwind utility classes via `slotProps`:

```tsx title="TailwindCalendar.tsx (React)"
import type { CalendarSlotProps } from '@ilamy/calendar'
import { IlamyCalendar } from '@ilamy/calendar/react'
import '@ilamy/calendar/styles/base.css'

const tailwindSlotProps: CalendarSlotProps = {
  root: {
    className: [
      'bg-background text-foreground text-sm',
      "[&_[data-ilamy-slot='arrow-group']]:border [&_[data-ilamy-slot='arrow-group']]:border-border [&_[data-ilamy-slot='arrow-group']]:rounded-md",
      "[&_[data-ilamy-slot='view-switcher']]:bg-muted [&_[data-ilamy-slot='view-switcher']]:rounded-md [&_[data-ilamy-slot='view-switcher']]:p-[3px]",
      "[&_[data-ilamy-slot='month-header']]:bg-background [&_[data-ilamy-slot='month-header']]:border-b [&_[data-ilamy-slot='month-header']]:border-border",
    ].join(' '),
  },
  navButton: {
    className:
      'bg-background text-foreground border border-border rounded-md px-3 text-sm font-medium hover:bg-muted data-[variant=primary]:bg-primary data-[variant=primary]:text-primary-foreground',
  },
  viewButton: {
    className: 'text-muted-foreground rounded-sm px-3 text-sm font-medium',
  },
  viewButtonActive: {
    className:
      'bg-background text-foreground rounded-sm px-3 text-sm font-medium shadow-xs',
  },
  grid: {
    className: 'bg-background border border-border rounded-none',
  },
  dayHeader: {
    className:
      "bg-background text-foreground py-2 text-sm font-medium [&:not(:last-child):not([data-last-col='true'])]:border-r [&:not(:last-child):not([data-last-col='true'])]:border-border",
  },
  cell: {
    className:
      "bg-background p-1 [&:not(:last-child):not([data-last-col='true'])]:border-r [&:not(:last-child):not([data-last-col='true'])]:border-border",
  },
  eventBar: {
    className:
      "rounded-sm text-xs font-medium [&:not([data-custom-color='true'])]:bg-primary [&:not([data-custom-color='true'])]:text-primary-foreground [&>[data-ilamy-part='event-bar-content']]:px-1.5 [&>[data-ilamy-part='event-bar-content']]:py-1 [&[data-compact='true']>[data-ilamy-part='event-bar-content']]:py-0",
  },
}

export function TailwindCalendar({ events }) {
  return <IlamyCalendar events={events} unstyled slotProps={tailwindSlotProps} />
}
```

The exact same `tailwindSlotProps` object works in Vue (`:slot-props="tailwindSlotProps" unstyled`), Svelte, Solid, and Angular.

## 3. StyleX Recipe (`--ilamy-*` Tokens + `slotProps`)

Keep `@ilamy/calendar/styles.css` loaded for structural and theme tokens, and pass StyleX tokens or compiled `stylex.props(...)` output directly through `slotProps`:

```tsx title="StylexCalendar.tsx"
import * as stylex from '@stylexjs/stylex'
import type { CalendarSlotProps } from '@ilamy/calendar'
import { IlamyCalendar } from '@ilamy/calendar/react'
import '@ilamy/calendar/styles.css'

const styles = stylex.create({
  root: {
    '--ilamy-bg': '#ffffff',
    '--ilamy-fg': '#0f172a',
    '--ilamy-surface': '#f8fafc',
    '--ilamy-muted': '#f1f5f9',
    '--ilamy-border': '#e2e8f0',
    '--ilamy-primary': '#2563eb',
    '--ilamy-primary-fg': '#ffffff',
    '--ilamy-radius': '8px',
    colorScheme: 'light',
  },
  eventBar: {
    borderRadius: 6,
    fontWeight: 600,
  },
})

const stylexSlotProps: CalendarSlotProps = {
  root: stylex.props(styles.root),
  eventBar: stylex.props(styles.eventBar),
}

export function StylexCalendar({ events }) {
  return <IlamyCalendar events={events} slotProps={stylexSlotProps} />
}
```

Because `stylex.props(...)` returns `{ className, style }`, the same object plugs into `slotProps` in Vue, Svelte, Solid, and Angular without any wrapper library.

## 4. Material UI Theme Recipe (`Theme` → `--ilamy-*` Variables)

Sync a Material UI `Theme` with the built-in calendar grid by mapping `theme.palette`, `theme.shape`, and `theme.typography` to `--ilamy-*` CSS custom properties in a small helper:

```tsx title="muiThemeToSlotProps.ts"
import type { CalendarSlotProps } from '@ilamy/calendar'
import type { Theme } from '@mui/material/styles'

export function muiThemeToSlotProps(theme: Theme): CalendarSlotProps {
  const radius =
    typeof theme.shape.borderRadius === 'number'
      ? `${theme.shape.borderRadius}px`
      : String(theme.shape.borderRadius)

  return {
    root: {
      style: {
        '--ilamy-bg': theme.palette.background.paper,
        '--ilamy-fg': theme.palette.text.primary,
        '--ilamy-surface': theme.palette.background.default,
        '--ilamy-muted':
          theme.palette.mode === 'dark'
            ? theme.palette.background.default
            : theme.palette.grey[100],
        '--ilamy-muted-fg': theme.palette.text.secondary,
        '--ilamy-border': theme.palette.divider,
        '--ilamy-primary': theme.palette.primary.main,
        '--ilamy-primary-fg': theme.palette.primary.contrastText,
        '--ilamy-danger': theme.palette.error.main,
        '--ilamy-radius': radius,
        '--ilamy-font': theme.typography.fontFamily ?? 'inherit',
        colorScheme: theme.palette.mode,
      },
    },
  }
}
```

```tsx title="MuiStyledCalendar.tsx"
import { useTheme } from '@mui/material/styles'
import { IlamyCalendar } from '@ilamy/calendar/react'
import '@ilamy/calendar/styles.css'
import { muiThemeToSlotProps } from './muiThemeToSlotProps'

export function MuiStyledCalendar({ events }) {
  const theme = useTheme()
  return <IlamyCalendar events={events} slotProps={muiThemeToSlotProps(theme)} />
}
```

You can combine this styling helper independently with native dialogs or with a MUI `Dialog` in [`slots.eventForm`](/docs/customization/components#material-ui-dialog-react).

## Cells During a Drag

While an event is dragged over the calendar, the grid wrapper carries `data-dragging="true"`. Built-in and custom cell selectors can use it to suppress hover highlights during a drag.
