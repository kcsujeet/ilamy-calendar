ilamy Calendar ships zero CSS. Out of the box it uses Tailwind CSS v4 + shadcn tokens, and in v4.0 it also supports **unstyled mode**, **`slotProps`**, swappable **`components`**, first-party **MUI** and **StyleX** theme adapters, and a framework-agnostic **headless core**.

## Default: Tailwind CSS v4 & shadcn/ui

<Aside type="caution">
When using the default Tailwind styling, register ilamy Calendar with Tailwind's `@source` directive so Tailwind scans its utility classes.
</Aside>

```css title="globals.css"
@source "../node_modules/@ilamy/calendar/dist";
```

## Unstyled Mode, `slotProps`, and Custom `components`

Pass `unstyled` to strip all default visual styling while keeping structural layout geometry intact. Style any slot with `slotProps`, or swap UI primitives (`Button`, `Input`, `Textarea`, `Label`, `Checkbox`, `Dialog`, `Select`, `Popover`) via `components`:

```tsx
import { IlamyCalendar } from '@ilamy/calendar'

<IlamyCalendar
  events={events}
  unstyled
  slotProps={{
    root: { className: 'my-calendar' },
    header: { className: 'my-header' },
    cell: { className: 'my-cell' },
    event: { className: 'my-event' },
    resizeHandle: { className: 'my-resize-handle' },
  }}
  components={{
    Button: MyDesignSystemButton,
  }}
/>
```

## Material UI (MUI) Adapter

Use `@ilamy/calendar/themes/mui` to render `@mui/material` primitives (`Button`, `TextField`, `Checkbox`, `Dialog`, `Select`, `Popover`) and MUI palette/surface tokens with zero Tailwind required:

```tsx
import { IlamyCalendar } from '@ilamy/calendar'
import { createMuiTheme } from '@ilamy/calendar/themes/mui'

const muiTheme = createMuiTheme()

<IlamyCalendar events={events} {...muiTheme} />
```

## StyleX Adapter

Use `@ilamy/calendar/themes/stylex` to style the calendar with atomic StyleX styles:

```tsx
import { IlamyCalendar } from '@ilamy/calendar'
import { createStylexTheme } from '@ilamy/calendar/themes/stylex'

const stylexTheme = createStylexTheme()

<IlamyCalendar events={events} {...stylexTheme} />
```

## Headless Core (`@ilamy/calendar/core`)

Building a calendar UI in Vue, Svelte, Solid, Web Components, or a fully bespoke React layout? Import the zero-React, zero-CSS engine directly from `@ilamy/calendar/core`:

```ts
import {
  createCalendarController,
  layoutHorizontal,
  layoutVertical,
  isRangeWithinBusinessHours,
} from '@ilamy/calendar/core'

const controller = createCalendarController({
  events,
  timezone: 'America/New_York',
  initialView: 'week',
})
```

## Cells During a Drag

While an event is dragged over the calendar, the grid wrapper carries `data-dragging="true"`. Day cells and time slots use it to suppress hover tints during drags (`not-in-data-dragging:hover:bg-accent`).

## Scrollbar Layout Shift (Optional)

When Radix dialogs or popovers open, `react-remove-scroll` locks body scroll. If you prefer to keep the scrollbar visible:

```css title="Optional: keep the scrollbar on dropdown/dialog open"
[data-scroll-locked][data-scroll-locked] {
  overflow-y: scroll !important;
  margin-right: 0 !important;
}
```
