# Development Log - 2026-08-22

## Changes

- **[drag preview]**: Reworked the drag overlay to render the normal event presentation at its measured source dimensions. The source remains visible at half opacity while the full-opacity preview follows the drag.
- **[drag preview sizing]**: Delegated preview dimensions to DnD Kit's measured overlay wrapper and made the event fill that wrapper, avoiding direct DOM measurement.
- **[drag preview cleanup]**: Removed cursor-centering and drop animations, portaled the overlay to the document body, and disabled the event enter animation inside the preview.
- **[drag preview architecture]**: Removed mirrored drag state and the imperative overlay ref. The overlay now reads DnD Kit's active data directly and renders a shared, non-draggable event presentation so the floating copy has no duplicate focus target.
- **[drag preview hardening]**: Removed redundant overlay sizing markup and configuration, added `style` to the existing event memo comparison, and preserved the calendar-event type guard when resolving drops.
- **[leading-edge drops]**: Timed events spanning multiple slots now resolve their destination from the floating preview's leading edge, preserving where the event was grabbed while continuing to snap by `slotDuration`.
- **[drop resolver contract]**: Made `slotDuration` a required resolver argument so the calendar context remains its only source of truth.
- **[scope reduction]**: Removed the proposed independent snap interval, DOM-scanning timed geometry resolver, drag time indicator, grid metadata changes, recurrence fix, and cell-range fix from this branch so those concerns can be handled separately.
