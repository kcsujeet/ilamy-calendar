# Development Log - 2026-11-09

## Changes

- **[agenda]**: A custom `renderEvent` now draws the agenda row's title (#394). The plugin ignored it because `renderEvent` was not on the public `IlamyCalendarApi`, and a plugin may read only that. The row keeps its time label and colour dot and hands the title and the `Day N/M` counter to the renderer, matching FullCalendar's list view, which passes only its title cell to `eventContent` (`ListViewEventRow.tsx`, v6.1.19). Each day's call gets its own `EventSegment`: `isStart` on the first listed day of the event, `isEnd` on the last.
- **[api]**: `IlamyCalendarApi` gains a read-only `renderEvent`, next to `renderCurrentTimeIndicator`, which was exposed the same way for the agenda.
- **[e2e]**: New `renderEventVariant=segment-flags` harness renderer writes `title start:<isStart> end:<isEnd>`, so a spec can read which slice each call drew.
