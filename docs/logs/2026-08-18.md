# Development Log - 2026-08-18

## Changes

- **[drag-and-drop]**: Added minute-accurate timed dragging with configurable 1, 5, 10, 15, 30, or 60 minute clock snapping. A one-minute interval effectively disables coarse snapping. The implicit interval follows the visual slot duration while an explicit interval remains independent from it. Dragging preserves the pointer grab offset, carries across hour/day boundaries, and retains event duration at millisecond precision.
- **[drag-and-drop UI]**: Added lane-scoped horizontal/vertical time indicators with 12/24-hour labels and a custom renderer contract. The floating preview now reuses normal event rendering and measured source dimensions while the source remains visible at half opacity.
- **[drag-and-drop overlay]**: Portaled the fixed floating preview and drag time indicator to `document.body` so transformed or backdrop-filtered calendar ancestors cannot offset them from the pointer or selected time.
- **[drag preview fidelity]**: Disabled preview scaling, enter animation, and drop animation; applied the measured source dimensions to both overlay layers so two-hour Week events retain their full height throughout the drag, then disappear immediately on release instead of collapsing to content height. When the drag library has not populated its initial rectangle at drag start, the preview now measures the actual source event element instead of collapsing to the title's intrinsic size.
- **[drag-and-drop cleanup]**: Removed redundant day-cell calculations from continuous drag movement, shared drop/cancel visual cleanup, and narrowed the event-update utility to the drag fields it actually consumes.
- **[drag synchronization]**: Resolved timed lanes from live viewport pointer coordinates and timed-cell geometry instead of lagging collision state or scroll-adjusted deltas. Anchored the preview to the source rectangle captured at drag start and bridged one-pixel layout gaps between adjacent cells and lanes. This keeps the preview and indicator synchronized during rapid movement and auto-scroll without flicker or cancelled boundary drops while preserving disabled and off-grid rejection.
- **[grid metadata]**: Timed cells now expose their real slot range, time axis, and destination lane. Snapped starts outside enabled visible cells are rejected while resource moves, all-day conversions, and scoped recurring updates continue through the existing mutation flow.
- **[public API/playground/docs]**: Exported `DragSnapInterval` and `RenderDragTimeIndicatorProps`; added `dragSnapInterval`, `showDragTimeIndicator`, and `renderDragTimeIndicator`; added playground controls and documented the new behavior.
- **[tests]**: Added interaction and geometry coverage for every snap interval, slot-derived defaults and explicit overrides, rounding and rollover, grab offsets, millisecond durations, indicator rendering/visibility/axes, resource context, preview fidelity (including the exact measured size of a two-hour Week event), lagging/null collision targets, shifted active rectangles, auto-scroll, one-pixel cell/lane gaps, disabled targets, and cleanup. The new behavior tests were regression-proved by temporarily restoring the previous behavior and observing the expected failures.
