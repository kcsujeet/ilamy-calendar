# Development Log - 2026-10-29

## Changes

- **[tooling]**: The kc-claude-kit plugins were renamed with a `kc-` prefix (kit #29), so the old names this repo enabled no longer exist in the marketplace and stop receiving updates. `.claude/settings.json` now enables `kc-gates`, `kc-conventions`, `kc-instructions`, `kc-verify`, `kc-usage-band` and `kc-image-preview`, and the docs name the renamed skills (`kc-gates:kc-code-review`, `kc-gates:kc-post-review`).
- **[tooling]**: The marketplace is declared by its HTTPS git URL instead of the `owner/repo` shorthand, which clones over SSH whenever an SSH key authenticates to GitHub. It matches how the marketplace is added on the owner's machine, so the two declarations no longer disagree and trigger a re-fetch.
- **[docs]**: AGENTS.md says `claude plugin install` takes one plugin per call (a multi-name call installs only the first, measured today), and that the kit's conventions load only as rule files (`/kc-conventions:kc-init`, or `~/.claude/rules/` for every project), since a plugin cannot ship rules.

- `.agents/settings.json` - `enabledPlugins` uses the `kc-` names; the marketplace source is its HTTPS git URL

The kc-gates project-conventions gate still reads `.claude/review-conventions.md`, and its posting hook still checks `KC_REVIEW_POST_APPROVED=1` (kit `main`), so nothing else in the repo depends on the old names.
