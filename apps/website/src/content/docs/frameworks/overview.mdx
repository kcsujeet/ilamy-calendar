`@ilamy/calendar` v4.0 is built around **one shared DOM renderer and built-in zero-dependency pointer drag/resize engine**, **one framework-agnostic plugin system**, and **one CSS token contract (`--ilamy-*`)** — wrapped symmetrically for **React 19**, **Vue 3.5**, **Svelte 5**, **Solid 2.0**, **Angular 22**, and **Vanilla DOM**.

Every adapter runs on the exact same TC39 Temporal date core, shared view-model builders, layout engine, DOM renderer, and CSS styling contract (`@ilamy/calendar/styles.css`, `@ilamy/calendar/styles/stylex`, `@ilamy/calendar/styles/mui`). In React, custom UIs (`renderEvent`, `renderHeader` / `headerComponent`, `renderResource`, `renderEventForm`, `onMoreEventsClick`) mount cleanly through React portals while `useIlamyCalendarContext()` and `ref` preserve the React DX. **All adapters import zero `@dnd-kit/*`, zero `@radix-ui/*`, zero `@mui/material` runtime components, and zero Tailwind**, and non-React adapters ship zero React code.

## Entry Points

| Target | Import | Version | What it exports |
| --- | --- | --- | --- |
| **Headless Core** | `@ilamy/calendar` | Any JS/TS | `createCalendarController`, Temporal helpers, layout engines, shared view-model builders, `defaultTranslations`, `createTranslator`, shared domain types (`CalendarEvent`, `Resource`, `BusinessHours`, `Translations`, `IlamyPlugin`, etc.) |
| **React** | `@ilamy/calendar/react` | React 19.2+ | `<IlamyCalendar />`, `useIlamyCalendarContext`, `CalendarThemeProvider`, `useSlotProps`, `SLOT_*` (renders via the shared DOM engine + React portals for custom UIs) |
| **Vue** | `@ilamy/calendar/vue` | Vue 3.5+ | `<IlamyCalendar />` component (props, emits, scoped slots `#event`/`#header`/`#resource`/`#event-form`, `expose()`), `useIlamyCalendar` composable |
| **Svelte** | `@ilamy/calendar/svelte` | Svelte 5+ | `ilamyCalendar` Svelte 5 Attachment (`{@attach}`), `ilamyCalendarAction` (`use:`), `createIlamyCalendar` (`svelte/reactivity`) |
| **Solid** | `@ilamy/calendar/solid` | Solid 2.0+ | `<IlamyCalendar />` component, `createIlamyCalendar` (Solid 2 signals & memos) |
| **Angular** | `@ilamy/calendar/angular` | Angular 22+ | `registerIlamyCalendarElement`, `IlamyCalendarElement` (`<ilamy-calendar>` Custom Element with `[options]`/`[events]` & typed `CustomEvent`s), `createAngularCalendar` |
| **Vanilla DOM** | `@ilamy/calendar/dom` | Browser DOM | `mountCalendar`, `DomCalendarOptions`, `MountedCalendar`, render-context types |
| **Plugins (All Frameworks)** | `@ilamy/calendar/plugins/{recurrence,agenda,year,ical,drag-to-create}` | Any JS/TS | Framework-agnostic plugins (`recurrencePlugin`, `agendaPlugin`, `yearPlugin`, `icalPlugin`, `dragToCreatePlugin`) shared identically across React, Vue, Svelte, Solid, Angular, and Vanilla DOM via `plugins` |
| **Stylesheets & Token Mappers** | `@ilamy/calendar/styles.css`, `./styles/base.css`, `./styles/theme.css`, `./styles/stylex`, `./styles/mui` | Pure CSS / JS | Layered CSS (`@layer ilamy.base, ilamy.theme`) with shadcn/Base UI auto-bridging, plus pure token mappers for StyleX (`createStylexCalendarTheme`) and Material UI (`createMuiCalendarTheme`) |

## Bring Your Own Design System (Every Framework)

Every adapter shares **pure token-based styling** alongside **framework-native custom renderers**:

### Framework-Agnostic Styling & Token Mappers

- **Zero-config layered CSS (`@ilamy/calendar/styles.css`):** Works with zero Tailwind installed and automatically bridges shadcn/Base UI CSS variables (`--background`, `--foreground`, `--border`, `--primary`, `--muted`, `--radius`, `.dark`). For Tailwind v4, `@import '@ilamy/calendar/styles.css';` before `@import 'tailwindcss';` requires no `@source` directive.
- **StyleX (`@ilamy/calendar/styles/stylex`):** Pass `createStylexCalendarTheme({ mode: 'light' | 'dark' })` and `stylexSlot` / `createStylexSlotProps` across React, Vue, Svelte, Solid, Angular, or Vanilla DOM.
- **Material UI Tokens (`@ilamy/calendar/styles/mui`):** Pure `createMuiCalendarTheme(theme)` maps any MUI `Theme` palette, typography, and shape directly into `--ilamy-*` CSS tokens with zero `@mui/material` runtime components.
- **Unstyled + `slotProps` + `[data-ilamy-slot]`:** Import `@ilamy/calendar/styles/base.css` (structural layout only) or pass `unstyled: true` with `slotProps` (`root`, `header`, `toolbar`, `navButton`, `viewButton`, `viewButtonActive`, `grid`, `dayHeader`, `cell`, `cellToday`, `cellDisabled`, `cellNonBusiness`, `allDayRow`, `eventBar`, `resizeHandle`, `nowIndicator`, `moreLink`, `resourceHeader`) or override `[data-ilamy-slot="..."]` directly in CSS.

### Custom UI Renderers (Base UI, Radix, React Aria, MUI, Vuetify)

- **Zero-dependency native HTML defaults:** Built-in dialogs, popovers, inputs, selects, and checkboxes use semantic native HTML elements styled by `@ilamy/calendar/styles.css` (zero `@radix-ui/*`, zero icon packs, zero `@mui/material` runtime components).
- **Custom renderers across every framework:** Plug your own form, header, event, resource, or overflow UI into the shared DOM renderer using `renderEvent`, `renderHeader` / `headerComponent`, `renderResource`, `renderEventForm`, and `onMoreEventsClick` (mounted through React portals in `@ilamy/calendar/react`, Vue scoped slots `#event` / `#header` / `#resource` / `#event-form`, or DOM mount hooks), while `--ilamy-*` tokens keep theme colors and spacing synchronized automatically.
