# Development Log - 2026-09-22

## Changes

- **[scroll-time]**: Changing `scrollTime` on a mounted calendar now scrolls to the new hour straight away. `useScrollToTime` dedupes its scroll so ordinary re-renders leave the user's scroll alone, but the dedupe key was only `${view}-${date}`, so a new `scrollTime` was ignored until the next navigation. The key now includes `scrollTime`. FullCalendar reapplies a changed `scrollTime` immediately.
- **[e2e harness]**: The harness re-reads the URL on `popstate`, and `setSettings(page, …)` changes settings on the mounted calendar. Navigating can't reproduce a runtime prop change, because the calendar would remount with the new value.
