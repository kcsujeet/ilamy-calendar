# Development Log - 2026-11-23

## Changes

- **[v4/phase0-spike]**: Completed Phase 0 spike proving both dual-JSX hygiene (`preact@11.2.0` internal renderer alongside React 19 + Svelte 5.59.1 adapters) and region-level slot lifecycle (`header`, `event`, `resource`, `eventForm`, `moreEventsDialog`, `recurrenceScopeDialog`) across React (`@base-ui/react@1.9.0`) and Svelte (`bits-ui@2.22.0`).
- **[findings]**:
  - Adding `/** @jsxImportSource preact */` to internal Preact `.tsx` modules is mandatory while React and Preact `.tsx` coexist across `bun check`, `bun test`, and Vite `@vitejs/plugin-react` (without the pragma, React's JSX runtime emitted frozen vnodes that crashed Preact with `Attempting to define property on object that is not extensible`).
  - Subscribing `SpikeCalendar` to `HeadlessCalendarController` inside `useLayoutEffect` (rather than `useEffect`) prevents missed updates immediately after mount, and gating `SpikeReactCalendar`'s update `useEffect` with shallow option equality prevents a React-Preact portal re-render loop.
  - Exporting explicit `: ReactNode` return annotations satisfies `isolatedDeclarations` in `bunup` DTS builds, with `0` `preact` references leaked into `dist-spike/**/*.d.ts`.
  - Measured `preact@11.2.0` real bundle cost: `14,012 B` raw / `5,909 B` gzip tree-shaken (`preact` + `preact/hooks` + `preact/jsx-runtime`), and `16.40 KB` raw / `5.92 KB` gzip shared spike renderer chunk.
