# Development Log - 2026-09-25

## Changes

- **[sticky titles]** (#290, review fixes on yesterday's uncommitted work): The code review (kc-claude-kit `review-code`) failed 7 gates. Each finding is fixed below.
- **[sticky insets]**: The time/date gutter is now marked `data-sticky-inset="left"`.
  - Before, a vertical grid with no all-day row (vertical resource month) published `--ilamy-sticky-left: 0px` beside a 64px sticky gutter. That contradicted the docs, and a custom title reading the variable stuck under the gutter.
  - The gate's 🔴 rating (default title breaks) was wrong: the default vertical title reads only `top`. Re-rated 🟠.
- **[drag mirror]**: Both snapped mirrors now keep their title in view like the bar does. Their title wears the same class, so a dragged long event's mirror no longer hides its title under the resource column or above the scrolled grid.
- **[event surface]**: The sticky-title classes moved to one lookup, `STICKY_TITLE_CLASS` in `lib/utils/event-surface.ts`, shared by `DefaultEventContent` and both drag previews. This replaced the multi-line ternary in `DefaultEventContent`.
- **[useStickyInsets]**:
  - The hook reads `view`, `currentDate` and `stickyViewHeader` from context itself and takes only a lane count, so the two grids no longer build the same key inline.
  - The key comes from a new `keys.stickyInsets` entry (the central key factory, `dayKey` for the date) rather than ad-hoc concatenation.
  - The header containers share `getHeaderStickyInset` for their on/off marker.
- **[e2e harness]**: The URL setting `eventContent` is renamed `renderEventVariant`. `eventContent` is FullCalendar's name for the content callback (`core/src/common/EventContainer.tsx:76-77`, v6.1.15), not for a preset selector. The harness renderer's title is now 10px, so it fits an 80px resource column with room to slide.
