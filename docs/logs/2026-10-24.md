# Development Log - 2026-10-24

## Changes

- **[fix]**: A `translations` object that lacks a key at runtime (a 3.2.1 app's object has none of the nine keys 3.3 added) now falls back to the English default, then to the key. `useCalendarConfig` read `dict[key] || key`, so the pickers rendered "selectTime". An empty string still counts as missing (`||`, as before), so a label cannot be blanked by accident; it now shows English instead of the raw key. The `Translations` type is unchanged (still every key, `docs/translation-usage.md`), and the `translator` path is untouched.
- **[fix]**: The `ref` handle wrote `latestApiRef.current` during render. React: "Do not write or read `ref.current` during rendering" (react.dev/reference/react/useRef, Caveats). A render React discards left the consumer's `ref` reading an API that never committed. It is now written in `useInsertionEffect`, the idiom of `useLatestHandler`.
- **[test]**: Unit: three cases in `use-calendar-engine.test.ts` (missing key, unknown key, empty string); two in `ilamy-calendar.test.tsx` (layout-effect read, and a `startTransition` navigation that suspends below the handle and is abandoned). E2E: `translations.spec.ts` with a new harness-only `translations=pre-3.3` parameter.
- **[docs]**: `docs/translation-usage.md` sentence; CHANGELOG 3.3.0 translations wording, the three unrendered `{L(n)}` links (#362, #341, #350, all merged) and the bundle line (re-measured).
