# Development Log - 2026-08-31

## Changes

- **[calendar/drag-and-drop]**: replaced rectangle-based drop positioning with a delta between the first hovered calendar cell and the final drop cell. Applying that delta to the event's original start preserves the grab offset without depending on slot height or `slotDuration`.
- **[calendar/drag-and-drop]**: kept all-day boundary changes and events dragged from the all-events dialog as absolute destination drops.
- **[calendar/drag-and-drop]**: reused each droppable cell's canonical start instead of reconstructing it from parallel date/hour/minute fields, and consolidated active-event data lookup inside the drop resolver.
- **[calendar/drag-and-drop]**: kept disabled cells collision-visible so they can act as drag origins while still rejecting them as destinations, and preserved event duration at millisecond precision.
- **[calendar/drag-and-drop]**: named the outside-grid override `useDestinationTime` and documented why dialog events require an absolute destination time instead of a cell delta.
- **[calendar/cells]**: preserved `getCellRange`'s existing sub-minute behavior; canonical drag metadata now reuses the computed start without normalizing it.

## Files Modified

- `packages/calendar/src/components/drag-and-drop/calendar-dnd-context.tsx` - tracks the first hovered cell for each drag and clears it after drop or cancellation
- `packages/calendar/src/components/drag-and-drop/dnd-utils.ts` - applies cell-date deltas and removes rectangle and slot-duration calculations
- `packages/calendar/src/components/drag-and-drop/calendar-dnd-context.test.tsx` - covers origin tracking, cancellation cleanup, and outside-grid drops
- `packages/calendar/src/components/drag-and-drop/dnd-utils.test.tsx` - covers grab-offset preservation, cross-day/resource movement, DST, and all-day conversion
- `packages/calendar/src/components/draggable-event/draggable-event.tsx` - identifies and documents drags that should use the destination time directly
- `packages/calendar/src/components/all-events-dialog.tsx` - marks dialog events to use their destination time because they have no source grid cell
- `packages/calendar/src/components/droppable-cell.tsx` - supplies canonical cell starts and disabled-state metadata to drag-and-drop without removing disabled origin cells from collision detection
- `packages/calendar/src/components/droppable-cell.test.tsx` - pins preservation of seconds and milliseconds in a supplied cell date

- The faithful full-size drag overlay and source opacity behavior are unchanged.
- Regression tests use the same `day-cell` metadata produced by the real grid; the new disabled-origin and millisecond assertions failed before the cleanup.
