Get up and running with ilamy Calendar in just a few minutes.

## Basic Setup

Once you've installed `@ilamy/calendar`, follow these steps to configure and use the calendar:

<Steps>

1. ### Import the Layered Stylesheet

   Import `@ilamy/calendar/styles.css` once in your application. It ships `@layer ilamy.base, ilamy.theme` and works standalone with **zero Tailwind installed** — no `@source` directive needed:

   ```ts title="main.tsx"
   import '@ilamy/calendar/styles.css';
   ```

   If your app uses Tailwind CSS v4 (or shadcn/ui), import it **before** `@import 'tailwindcss';` in your CSS file:

   ```css title="globals.css"
   @import '@ilamy/calendar/styles.css';
   @import 'tailwindcss';
   ```

   <Aside>
   When shadcn CSS variables (`--background`, `--foreground`, `--border`, `--primary`, `--muted`, `--radius`, `.dark`) are present on the page, `--ilamy-*` tokens inherit them automatically.
   </Aside>

2. ### Import and Use the Calendar

   Import `IlamyCalendar` from `@ilamy/calendar/react` (or use `@ilamy/calendar/vue`, `@ilamy/calendar/svelte`, `@ilamy/calendar/solid`, `@ilamy/calendar/angular`, or `@ilamy/calendar/dom`). Events accept plain ISO 8601 strings or native JavaScript `Date` objects:

   ```tsx title="MyCalendar.tsx"
   import { IlamyCalendar } from '@ilamy/calendar/react';
   import type { CalendarEvent } from '@ilamy/calendar';
   import '@ilamy/calendar/styles.css';

   const events: CalendarEvent[] = [
     {
       id: '1',
       title: 'Team Standup',
       start: '2026-03-02T09:00:00-05:00',
       end: '2026-03-02T09:30:00-05:00',
     },
   ];

   export default function MyCalendar() {
     return (
       <div style={{ height: '600px' }}>
         <IlamyCalendar events={events} editable />
       </div>
     );
   }
   ```

3. ### Add plugins (optional)

   The core ships **no plugins** by default. Capabilities like recurring events, agenda view, year view, iCalendar export, and drag-to-create are opt-in: import them from their subpath and register them via the `plugins` prop. Skip this step if you don't need them.

   ```tsx title="MyCalendar.tsx"
   import { IlamyCalendar } from '@ilamy/calendar/react';
   import { recurrencePlugin } from '@ilamy/calendar/plugins/recurrence';
   import { yearPlugin } from '@ilamy/calendar/plugins/year';
   import { icalPlugin } from '@ilamy/calendar/plugins/ical';

   export default function MyCalendar() {
     return (
       <div style={{ height: '600px' }}>
         <IlamyCalendar
           plugins={[recurrencePlugin(), yearPlugin(), icalPlugin()]}
         />
       </div>
     );
   }
   ```

</Steps>
