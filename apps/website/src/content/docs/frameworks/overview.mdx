`@ilamy/calendar` v4.0 ships first-party, ready-to-use adapters for **React 19**, **Vue 3.5**, **Svelte 5**, **Solid 2.0**, and **Angular 22** from one package — plus the framework-agnostic headless engine at `@ilamy/calendar/core`.

Every adapter runs on the same TC39 Temporal date core, layout engine, RFC 5545 recurrence engine, business-hours & constraint validator, and styling primitives (`unstyled`, `slotProps`, Tailwind/shadcn default tokens, and `@ilamy/calendar/themes/stylex`). **Vue, Svelte, Solid, and Angular bundles import zero React code.**

## Entry Points

| Framework | Import | Version | What it exports |
| --- | --- | --- | --- |
| **React** | `@ilamy/calendar` | React 19.2+ | `<IlamyCalendar />`, `useIlamyCalendarContext`, MUI & StyleX theme adapters, plugins |
| **Vue** | `@ilamy/calendar/vue` | Vue 3.5+ | `<IlamyCalendar />` component (props, emits, scoped slots `#event`/`#header`/`#resource`/`#event-form`, `expose()`), `useIlamyCalendar` composable |
| **Svelte** | `@ilamy/calendar/svelte` | Svelte 5+ | `ilamyCalendar` Svelte 5 Attachment (`{@attach}`), `ilamyCalendarAction` (`use:`), `mountIlamyCalendar`, `createIlamyCalendar` (`svelte/reactivity`) |
| **Solid** | `@ilamy/calendar/solid` | Solid 2.0+ | `<IlamyCalendar />` component, `mountSolidCalendar`, `createIlamyCalendar` (Solid 2 signals & memos) |
| **Angular** | `@ilamy/calendar/angular` | Angular 22+ | `registerIlamyCalendarElement` (`<ilamy-calendar>` Custom Element with `[options]`/`[events]` & typed `CustomEvent`s), `createAngularCalendar` (Angular 22 Signals), `mountAngularCalendar` |
| **Headless Core** | `@ilamy/calendar/core` | Any JS/TS | `createCalendarController`, Temporal helpers, `layoutHorizontal`, `layoutVertical`, business hours & constraints |

      readonly calendarOptions = computed(() => ({
        events: this.events(),
        timezone: 'America/New_York',
        editable: true,
        nowIndicator: true,
        enableIcalExport: true,
      }))

      }
    }

## Bring Your Own Design System (Every Framework)

All five frameworks share the exact same customization contract:

- **Tailwind / Shadcn (default):** Add `@source "../node_modules/@ilamy/calendar/dist";` to your CSS file.
- **StyleX:** Pass `createStylexCalendarTheme({ mode: 'light' | 'dark' })` from `@ilamy/calendar/themes/stylex` to React, Vue, Svelte, Solid, or Angular.
- **Unstyled + `slotProps`:** Pass `unstyled: true` with `slotProps` (`root`, `header`, `toolbar`, `navButton`, `viewButton`, `viewButtonActive`, `grid`, `dayHeader`, `cell`, `cellToday`, `cellDisabled`, `cellNonBusiness`, `allDayRow`, `eventBar`, `resizeHandle`, `nowIndicator`, `moreLink`, `resourceHeader`) to style with CSS Modules, Vanilla Extract, UnoCSS, or plain CSS.
- **Custom renderers:** Override events, headers, resources, and event forms using native React props, Vue scoped slots (`#event`, `#header`, `#resource`, `#event-form`), or DOM mount hooks (`renderEvent`, `renderHeader`, `renderResource`, `renderEventForm`).
- **Material UI (`@ilamy/calendar/themes/mui`):** Native MUI component adapter for React consumers.
