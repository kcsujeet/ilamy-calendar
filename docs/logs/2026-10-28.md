# Development Log - 2026-10-28

## Changes

- **[horizontal layout]**: Hour-axis row allocation now reserves the exact half-open intervals used to draw bars. Events ending and starting at 09:17 reuse a row. All hourly events compete by start time (longer first at an equal start), including short events nested under longer ones. The day axis keeps its whole-day allocation and priority rules.
- **[row sizing and overflow]**: `useProcessedWeekEvents` supplies a single cell layout containing its events, required row count and hidden count. Both flat and grouped horizontal cells consume it. Height follows the highest occupied row, and successive events in one hour no longer create false overflow. Visible column indices come directly from placement, including a clipped suffix, rather than reverse-engineering percentages.
- **[regression coverage]**: Algorithm and component tests cover exact-minute handoffs, gaps, real overlaps, same-hour chains, nested events in either input order, instant events, clipped suffixes, grouped columns, height placeholders, hidden counts and unchanged day-grid behavior. Demo specs cover these layouts, independent resources, overflow dialogs and real-pointer edit/save and resize interactions verified in the demo’s published lifecycle updates.
- **[docs]**: `docs/time-grid.md` describes exact-interval row allocation and shared cell layout. Retired the oldest daily log (`2026-10-02.md`) to retain ten files.
