# Development Log - 2026-10-03

## Changes

- **[structure]** State follows Bulletproof React's `stores/` (https://github.com/alan2207/bulletproof-react/blob/master/docs/project-structure.md: `stores` holds a feature's state, `contexts` is not one of its folders). One folder per context, each with its own context file and a specifically named provider:
  - `features/calendar/stores/calendar-context/`: `calendar-context.ts` (`CalendarContext`, was `contexts/calendar-context/context.ts`), `calendar-provider.tsx` (`CalendarProvider`, was `provider.tsx`).
  - `features/calendar/stores/calendar-cell-context/`: `calendar-cell-context.ts` (`CalendarCellContext`), `calendar-cell-provider.tsx` (`CalendarCellProvider`, which reads the calendar context and provides the memoized subset; `CalendarProvider` renders it around its children, so data flows calendar -> cell).
  - `src/contexts/` (drag preview, grid axis) moved to `src/stores/`.
  - Each test sits beside its unit (the "cell context survives an event change" test moved to `calendar-cell-provider.test.tsx`). `docs/v2-overhaul-plan.md`'s "Target structure", which had recorded a feature-level `contexts/` folder, now says `stores/`; `CLAUDE.md` key paths updated.
  - The cell hook lives in `hooks/use-calendar-cell-context.ts`, not in `use-smart-calendar-context.ts` (which holds the full-context hook and the public `useIlamyCalendarContext`). It was never public: `index.ts` re-exports only `useIlamyCalendarContext` and `IlamyCalendarApi` by name.
- **[review fixes, #308 round 1]** Recurrence memo: the validity checks and the window check name their operands, the unchecked `event.rrule as RRuleOptions` is gone (the caller passes the narrowed rule), and two tests now change the rule and the start on the same event object (both fail if the validity check is removed; before, deleting it left every test green). `AllEventDialogHandle` matches the component's name. Named operands in the hit-test, the "+N more" key check and the month-padding check; the hit-test reads edges one at a time with early returns, which keeps its laziness.
